# Contributing

Thanks for helping make agent-assisted infrastructure work safer.

Before opening a pull request:

1. Keep examples synthetic.
2. Do not include private hostnames, IPs, secrets, logs, or runtime state.
3. Run `python -m pip install -e ".[dev]"` and `python -m pytest`.
4. Make the PR claim boundary explicit.

PRs should describe what was proven and what was not proven.
