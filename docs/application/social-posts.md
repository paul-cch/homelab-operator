## Maintainer-Focused

Coding agents are useful in infrastructure repos, but source checks can sound
like deployment proof if the claim boundary is vague.

Homelab Operator checks that PRs and receipts say what was actually proven:
repo source, GitHub coordination, host checkout, runtime export, live config, or
external service. The launch demo is synthetic and `repo_only`.

`https://github.com/paul-cch/homelab-operator`
